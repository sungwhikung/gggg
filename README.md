# Gryffindor · 겨울밤 기숙사 방

눈 내리는 겨울 저녁, 등잔불 하나가 켜진 돌벽 기숙사 방을 가만히 틀어 두는 앰비언트 화면입니다.

- 방은 Blender Cycles로 렌더했고, 조명마다 따로 뽑은 레이어를 브라우저(WebGL)에서 섞어 불빛이 일렁입니다.
- 창밖 눈과 바람·눈·불 소리는 페이지가 그 자리에서 만들어 내서 반복 구간이 없습니다.

**조작**

- 창문을 누르면 소리가 켜지고 꺼집니다. (키보드 M)
- 컵을 누르면 전체 화면이 됩니다. (키보드 F)
- 빈 곳을 누르면 제목이 잠깐 나타납니다.
